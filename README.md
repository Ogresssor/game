# 📁 Дело № 2110-МБ — о признании Александра НЕ холодным

Обложка дела → мини-игра «растопи лёд» (экспертиза температуры) → акт с подписью пальцем и печатью → доверенность с галочками → итоговая картинка с подписями, которую можно отправить или сохранить.

Без сборки: `index.html` + `style.css` + `script.js`.

Настройки в начале `script.js`: `TAPS` (сложность игры), `FINAL_TEMP`, `POWERS` (пункты доверенности), `TELEGRAM` (необязательные уведомления).
